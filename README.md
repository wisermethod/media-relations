# Media Relations

A WISER plugin for earned media at a company of any kind: pitching reporters, newsjacking, and bylined writing. No skills or experts have been built yet; an expert bench for that work, with skills under each expert, is the first planned.

## Install

Point your harness at this repository as a plugin root, or add the repository as a marketplace and install `media-relations@wiser-method-media-relations` from its catalog.

Work lands in the working folder you attach, never in this repository.
